# Scout

**AI workflow capture and desktop agent** — by [Orage AI Agency](https://orage.agency).

Scout records how you work, turns it into reusable skills, and puts a local AI agent on your desktop that can take work off your plate. Everything stays on your machine.

## Download

Grab the latest installer from the [Releases page](https://github.com/Orage-Agency/Scout-Releases/releases/latest):

| Platform | File | Notes |
|---|---|---|
| macOS | `Scout Mac.dmg` | Signed & notarized by Apple — opens with no warnings |
| Windows | `Scout Windows.exe` | One-click installer |
| Linux | `Scout Linux.AppImage` or `Scout Linux.deb` | AppImage: `chmod +x` and run |

## Install

- **Mac:** open the DMG, drag Scout to Applications.
- **Windows:** run the installer; Scout launches when done.
- **Linux:** `chmod +x "Scout Linux.AppImage" && ./"Scout Linux.AppImage"` — or `sudo dpkg -i "Scout Linux.deb"`.
